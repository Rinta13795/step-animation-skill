# 引擎 API（engine/engine.js）

课程文件里可以直接用下面这些全局函数和常量。

## 课程结构

```js
const LESSON = { title: '网页标题' };        // build.mjs 从这里取 <title>

SC.push({
  n: '① 节名',                               // 上方标签上的字
  code: '整段代码（可选）',                  // 有它时，step.c 可以写行号
  build() {                                  // 搭舞台，返回 S（会传给每一步的 run）
    const g = grid([[1, 2], [3, 4]], { label: '输入' });
    const r = valBox('结果');
    stage.appendChild(flow(g, r));
    return { g, r };
  },
  steps: [
    { c: 'x = a[0]',                         // 代码：字符串，或行号（数字 / 数组，从 1 数）
      p: '说明，可以用 <b>加粗</b> 和 <code>代码</code>',
      wait: 0,                               // 可选：动画很长时额外多停的毫秒数
      run(S) { /* 这一步的变化 */ } },
  ],
});
```

课程文件在自己的作用域里运行（build.mjs 会把它包在一个函数里），所以课程里的变量名、函数名随便起，不会覆盖引擎的函数。

## 常量
| 名字 | 值 | 用途 |
|---|---|---|
| `CO` | 橙 `#D85A30` | 正在读（橙框）、飞行数字默认色 |
| `BL` | 蓝 `#378ADD` | 正在写（蓝框）、指针 |
| `GN` | 绿 `#1D9E75` | 完成 / 找到 |
| `RD` | 红 `#E24B4A` | 竖线、警示 |
| `GR` | 灰 `#888780` | 次要的线、次要飞行数字 |
| `INST` | 布尔 | 现在是不是「瞬间重放」模式 |
| `stage` | 元素 | 舞台 |

## 布局
| 函数 | 说明 |
|---|---|
| `row(a, b, …)` | 横着排，不带箭头 |
| `flow(a, b, …)` | 横着排，中间加 → 箭头（表示数据流向） |
| `col(a, b, …)` | 竖着排 |

参数可以是元素，也可以是 `grid`/`valBox`/`vars`/`table`/`chart` 返回的对象（会自动取 `.w`）。

## 格子 `grid(m, o)`
- `m`：二维数组；一维数组会当成一行。`null` = 空格子（虚线）。
- `o.s` 格子边长（默认 52）；`o.fs` 字号；`o.label` 上方标题；`o.idx` 显示列号；`o.img` 按亮度（0~255）给格子上色；`o.hide` 上色但不显示数字；`o.st(r, c, v)` 自定义每格初始状态；`o.below` 下方给指针留几行（每行 22px，同一格子最多会叠几个指针就写几）。
- 返回 `G`：
  - `G.c(r, c)` / `G.c(列)`：取一个格子元素
  - `G.set(r, c, 值, 状态)`：改值 + 状态，带「弹一下」
  - `G.get(r, c)`：读当前值
  - `G.all()`、`G.rng(r0, c0, r1, c1)`、`G.cols(c0, c1)`：取一组格子（给 `frame` 用）
- 状态：`''` 默认、`'img'` 亮度色、`'imgh'` 亮度色不显示数字、`'pos'` 绿、`'neg'` 红、`'hl'` 黄、`'dim'` 变淡、`'done'` 灰掉、`'empty'` 虚线空格。

## 结果框 / 变量 / 表格
- `valBox(label, {w, fs, h})` → `{w, el, set(文字), clear()}`
- `vars(['lo', 'hi'], '变量')` → `{w, set(名字, 值), el(名字), row(名字)}`；`set` 时那一行会闪一下黄色。`el(名字)` 是值那一小块，适合当 `fly` 的起点终点；要给某个变量画框，用 `frame('b', BL, [V.row('lo')])` 框整行更好看。
- `table([[表头…], [行…], …], {label, head: true})` → `{w, el, trs, add(行数组, 标红?), cell(r, c)}`

## 动画
| 函数 | 说明 |
|---|---|
| `frame(名字, 颜色, 格子们, pad=5)` | 画框。同名框再次调用会平滑移动；格子们为空时隐藏该框 |
| `noFrame(名字…)` | 隐藏框；不写名字 = 全部隐藏 |
| `mark(名字, 格子, 文字, 颜色, 'below'/'above')` | 指针标签；同名的会平滑移动；同一格子上的多个自动错开 |
| `noMark(名字…)` | 隐藏指针；不写名字 = 全部 |
| `fly(从, 到, 文字, then, 颜色, 延迟ms)` | 数字从一个元素飞到另一个，落地执行 `then`。瞬间模式下直接执行 `then`。不需要的参数填 `null`：比如默认颜色 + 延迟 200ms 写 `fly(a, b, '3', null, null, 200)` |
| `swapFly(a, b, a的文字, b的文字, then)` | 两个格子交换（交叉飞） |
| `T(fn, ms)` | 延迟执行；瞬间模式下立即执行。**代替 setTimeout** |

## 折线图 `chart(o)`
- `o.w`、`o.h` 尺寸；`o.xmin/xmax/xt` 横轴范围和刻度；`o.ymin/ymax/yt` 纵轴；`o.xl`、`o.yl` 轴名；`o.label` 图上方标题；`o.fmt` 纵轴刻度格式化函数。
- 返回 `C`：
  - `C.line(xs, ys, 颜色, 线宽, 画线时长ms)`：折线，非瞬间模式下逐渐画出来
  - `C.dot(x, y, 颜色, 半径)`、`C.ring(x, y, 颜色)`：点、圈
  - `C.vline(x, 颜色)`、`C.hline(y, 颜色)`：竖/横虚线
  - `C.band(y0, y1, 颜色)`：横向色带（画在曲线下面）
  - `C.guide(x, y)`：从点到两条轴的虚线
  - `C.text(x, y, 文字, 颜色, 'start'/'middle'/'end', 字号, avoid=true)`：标注；默认自动上下挪，躲开其他文字、圆点和已经画好的曲线，并拉回边界内。传 `avoid=false` 就固定在给的位置
  - `C.legend([['名字', 颜色], …])`：右上角图例
  - `C.x(数据x)`、`C.y(数据y)`：数据坐标 → 像素
  - `C.svg`：SVG 元素（可以给 `frame` 用）

## 自检
网址后加 `?check`：每一步跑两遍，结果显示在页面顶部，并写入 `window.__CHECK__ = {ok, steps, problems: [{scene, step, kind, msg}]}`。
